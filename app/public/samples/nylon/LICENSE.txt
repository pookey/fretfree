Nylon guitar samples
====================

The files in this folder are the "Nylon String Guitar" preset (General MIDI
program 25) of the Fluid (R3) GM SoundFont by Frank Wen, rendered to one MP3
per note by the midi-js-soundfonts project (Benjamin Gleitzman), commit
044fab8e1456bfafc5776e86dfd6bb8697149aef. Each file is named by its MIDI note
number. scripts/fetch-samples.mjs regenerates them.
