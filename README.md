# Fretwork (working title)

An iPad-first guitar learning app (PWA; iPhone also supported). It teaches:

- where the notes are on the fretboard
- intervals
- chord construction
- the CAGED system
- diatonic harmony and common progressions
- ear skills

It teaches these with evidence-based methods: FSRS spaced repetition, retrieval practice, interleaving, fluency (speed) training, adaptive difficulty and faded guidance.

Production: https://guitar.dwellsee.com
